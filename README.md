## Описание

Проект перевода научной статьи в формат текстовой разметки markdown и автоматической конвертации в документ формата docx.

Выбранная статья: РОЛЬ ЦИФРОВЫХ ТЕХНОЛОГИЙ И ИСКУССТВЕННОГО ИНТЕЛЕКТА В РАЗВИТИИ ЭКОНОМИК СТРАН БРИКС

Автор статьи: Литвиненко А.В.

## Используемые инструменты

1. pandoc – утилита командной строки для преобразования документов между различными форматами разметки;
1. pandoc-crossref – плагин-фильтр для Pandoc, который добавляет поддержку нумерации рисунков, уравнений, таблиц и перекрёстных ссылок на них;
1. make для Windows – утилита для автоматической сборки проектов.
